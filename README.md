# mini-lovable
AI website generator for premium landing pages

## Kodmaskin-handoff

Kodmaskinens planner → executor → sandbox-kontrakt finns i
[docs/kodmachine-handoff.md](docs/kodmachine-handoff.md).
Den beskriver hur en DeerFlow/Hermes-planner lämnar över till en executor,
hur approval-gaten fungerar, och vilket return-format som gäller.

## Sandbox commands

- `npm run smoke-run` — repo-local MVP smoke loop: git status before, build, git diff --stat, git status after, plus a PASS/FAIL summary.
